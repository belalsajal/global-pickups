# Global Pickups

A peer-to-peer platform connecting travelers with people who need items delivered internationally.

## Features

- Travelers can earn money by utilizing unused luggage space
- Users can request items to be delivered internationally at reduced costs
- Secure escrow payment system
- User verification and rating system
- Global network covering 150+ countries

## Tech Stack

- React.js
- Material-UI
- React Router
- Framer Motion
